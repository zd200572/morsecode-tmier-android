# Morse Code Time - HarmonyOS 快速入门

## 前置要求

- DevEco Studio 5.0.0 或更高版本
- HarmonyOS SDK API 12
- HarmonyOS 设备或模拟器

## 快速开始

### 1. 打开项目

使用 DevEco Studio 打开 `morsecode_harmonyos` 目录。

### 2. 同步项目

等待 DevEco Studio 自动同步依赖和 SDK。

### 3. 运行应用

- 连接 HarmonyOS 设备或启动模拟器
- 点击工具栏的运行按钮
- 应用将自动安装并启动

## 功能演示

### 基础播报

1. 打开应用，界面显示当前时间
2. 顶部显示大号时间（如 `22 : 49`）
3. 中间显示对应的 Morse 码（如 `··−−− ··−−−` 和 `····− −−−−·`）
4. 底部显示 Morse 码的可视化符号（圆点和横条）

### 播放 Morse 码

1. 确保已启用至少一种输出方式（振动/声音/闪光）
2. 点击「▶ 播 报」按钮
3. 观察 Morse 码符号逐个高亮
4. 感受振动、声音或闪光灯的节奏

### 切换输出方式

- **振动**: 点击「振动」开关，启用后图标变为琥珀金色
- **声音**: 点击「声音」开关，启用后图标变为琥珀金色
- **闪光**: 点击「闪光」开关（仅在有闪光灯的设备上可用）

### 定时播报

1. 点击「定时播报」开关
2. 选择播报间隔：15 分钟 / 30 分钟 / 60 分钟
3. 系统将在每个整点/半点/刻钟自动播报时间

### 播报日期

1. 点击「播报设置」区域
2. 开启「播报日期」开关
3. 播报时将先播报日期（年月日），再播报时间

## Morse 码对照表

| 数字 | Morse 码 | 说明 |
|------|----------|------|
| 0 | `-----` | 五个长信号 |
| 1 | `.----` | 一个短信号，四个长信号 |
| 2 | `..---` | 两个短信号，三个长信号 |
| 3 | `...--` | 三个短信号，两个长信号 |
| 4 | `....-` | 四个短信号，一个长信号 |
| 5 | `.....` | 五个短信号 |
| 6 | `-....` | 一个长信号，四个短信号 |
| 7 | `--...` | 两个长信号，三个短信号 |
| 8 | `---..` | 三个长信号，两个短信号 |
| 9 | `----.` | 四个长信号，一个短信号 |

## 信号时长说明

- **短信号（·）**: 200ms
- **长信号（−）**: 600ms
- **符号间隔**: 200ms（同一数字内的信号之间）
- **字符间隔**: 600ms（不同数字之间）
- **时分分隔**: 1200ms（小时和分钟之间）

## 示例

### 时间 22:49 的 Morse 码

```
小时 22: ··−−− ··−−−
分钟 49: ····− −−−−·
```

### 播放顺序

1. 播放小时的第一个数字 `2`: `··−−−`
2. 播放小时的第二个数字 `2`: `··−−−`
3. 停顿 1200ms
4. 播放分钟的第一个数字 `4`: `····−`
5. 播放分钟的第二个数字 `9`: `−−−−·`

## 故障排除

### 振动不工作

- 检查设备是否支持振动
- 检查系统设置中是否启用了振动
- 检查应用权限是否已授予

### 声音不工作

- 检查设备音量是否开启
- 检查系统设置中是否启用了媒体音量
- 检查应用权限是否已授予

### 闪光灯不工作

- 检查设备是否有闪光灯
- 检查应用权限是否已授予
- 某些设备可能不支持闪光灯控制

### 定时播报不工作

- 检查是否已授予后台运行权限
- 检查是否已授予通知权限
- 检查系统电池优化设置
